# Mini World

Crie o MVP visual de um app mobile chamado "Mini".

CONCEITO:

Cada usuário terá um mini-eu 3D vivendo dentro do celular, inspirado em um brinquedo 3D cinematográfico, fofo e extremamente polido.

Nesta primeira etapa NÃO implemente IA, memória, autenticação, pagamentos, geração de avatar por IA ou conexão entre usuários.

OBJETIVO:

Criar somente a experiência visual inicial para validarmos o conceito.

TELA PRINCIPAL:

- interface mobile-first premium

- cenário 3D/visual de um pequeno quarto aconchegante

- personagem Mini centralizado

- personagem com aparência de boneco 3D estilizado

- animação sutil de respiração, piscar e pequenos movimentos

- toque no Mini deve gerar uma reação visual

- mostrar nome do Mini

- indicadores simples de Humor e Energia

- botões: Conversar, Brincar e Personalizar

- esses botões podem ser placeholders funcionais, sem backend

ESTÉTICA:

- visual cinematográfico

- iluminação suave

- materiais com aparência de brinquedo premium

- profundidade e sombras

- interface minimalista

- nada com aparência de dashboard ou sistema empresarial

- experiência semelhante a um pequeno mundo vivo dentro do celular

ARQUITETURA:

Use React + TypeScript.

Organize o código de forma limpa e modular para continuarmos posteriormente pelo Git.

Não crie banco de dados nem estruturas desnecessárias nesta etapa.

IMPORTANTE:

Priorize a qualidade visual da tela principal e deixe o projeto preparado para posteriormente adicionarmos Supabase, personagem persistente, memória, IA e interação entre Mini's.
